# Finite G1 shrink for L021 (sub-extension test on all (D1)/(D2) trace patterns of the 32 pieces of L*)

Date 2026-10-27. Tags: everything here is [verified-here as a computation, unrefereed]; the formula is [derived-here] (L022 Step 2.0).

## Question
G1 of results/proofs/L021-i11-deficiency-route.md: a degree-3 vertex v of a minimal counterexample H to KT^{L*} is the apex of (D1) (one special component F of H-v, k_v in {2,3} edges of v meeting F, Claim B: no minimum transversal of F meets all traces) or (D2) (two special components F1, F2, all three edges of v meet them, Claim B for the pair), with H-v strictly larger (G' nonempty). How many trace patterns survive when we test every induced sub-extension H[V(S) + v + Q'] against (i) membership in C (linear, F7-free, e(S) <= |S|-2), (ii) I11 (L016: I11 holds on C for <= 27 vertices, so s < 0 is impossible for such an induced subgraph), (iii) KT-minimality (any proper induced subgraph B of a minimal counterexample is in C_3 and has P(B) = A(B) + DEF(B) >= 0)?

## Formula (re-derived from L022 Step 2.0)
B = H[V(F) u {v} u Q] with n(B) = n_F + |Q| + 1, m(B) = m_F + k + k' (k edges at v, k' further edges inside Q), tau(B) = tau_F + t. Because T n V(F) is a transversal of F, t >= 0, so
  s(B) = 3n + 2m - 11 tau = s_F + 3(|Q|+1) + 2(k+k') - 11 t   (identity with t := tau(B) - tau_F; L022 states "<=" because only a lower bound on t is proved).
Coverage rule: a transversal T of B with |T| <= tau_F has v not in T (else T - v would be a transversal of F of size < tau_F), hence T = T n V(F) is a minimum transversal of F meeting the trace e n V(F) of every included edge at v (and no edge inside Q). So for k' = 0: t = 0 iff some minimum transversal of F meets all traces of the included v-edges, else t = 1 (T u {v}). Under Claim B the full structure has t = 1. KT-potential: A(B) = 27n + 35m - 132 tau = -W(F) + 27(|Q|+1) + 35(k+k') - 132 t. For (D2) the same with S in {F1+F2, F1, F2}; vertices of the other piece's traces count as Q-vertices (forced F2 edges only if three of them form an F2 edge; then tau is computed exactly).
Q' ranges over all subsets of the pattern's own outer vertices (D1) / all edge subsets J (D2): Q'(J) = non-S vertices of the edges in J. Unknown extra edges g inside Q' (>= 1 outer vertex, no two vertices on one v-edge) are handled as variants: a pattern is killed by a sub-extension only if every variant lying in C is also negative (I11: s < 0, n <= 27; KT: A + DEF < 0 with DEF over ALL L*-families of B including B itself, proper=False; an earlier run with proper=True wrongly "killed" 27 patterns whose sub-extension is itself a (10,7,4) piece, P = 0; fixed).

## Method / files
- g1lib.py: exact membership in C (linear, F7, P3 via Hall/matching over pairs; in_C_v uses only pairs {v,x}, sound because the components of B - v lie in C; agreed with in_C on 5,626 random patterns), induced subgraphs.
- d1.py: (D1): all k = 2, 3 patterns (parts = 1 or 2 vertices of piece-degree <= 2, disjoint, size-2 part not inside a piece edge, k = 2 adds a fully outer third edge), filtered by Claim B (bitsets over the list of minimum transversals), then C-membership of the full F', then the sub-extension tests. Reuses experiments/prover/L021/kt.py (pieces from closure_results.json, tau, minimum transversals, DEF).
- d2.py: (D2): all 528 unordered pairs of the 32 pieces (including a piece with itself), all unordered triples of edge types (a in F1, b in F2, rest outer), Claim B via bitsets over (T1,T2) pairs, sub-extension tests for S x J, C-membership of the full F'.
- check_formula.py: brute-force check. agg.py: aggregation.
Commands (nice -n 10, one process each): `python3 d1.py`; `python3 d2.py all 0 32` (about 30 min); `python3 check_formula.py`; `python3 agg.py`.

## Conclusion
This finite test does not shrink G1: of 244,373 Claim-B patterns, 5,074 + 238,978 survive (about 97.7%); the only killed ones are the 6 F7 assemblies (already excluded) plus patterns with F' not in C (D1: 241, 74 void). Reason: I11 (L016) can only kill an induced subgraph that is already outside C, so it adds nothing beyond C-membership, and a kill needs a pair of edges at v whose traces are not simultaneously coverable, which Claim B patterns almost never have; KT-minimality on the sub-extensions kills nothing because every sub-extension with A < 0 is itself a piece of L* (P = 0). Local information around v is therefore insufficient; G1 needs non-local input (the E1-hub lemma / structure of G').

## Caveats
- Q' only contains vertices of the pattern itself; unknown vertices of G' are not used. Only Delta <= 3 patterns with traces of piece-degree <= 2 (Delta <= 3 of H), k_v = 3 for (D2) (Theorem 4(b)), k_v in {2,3} for (D1). (D3) not treated.
- Patterns are counted as unordered triples/pairs of edges at v but NOT modulo automorphisms of the pieces; for a pair (F,F) the swap F1 <-> F2 counts a pattern twice. Pairs are unordered classes of pieces.
- D2 C-membership is tested for the full F' only (F7, P3 with hub v); D1 uses the complete test. Unrefereed; no certificate.
- An earlier D2/D1 run with DEF over proper induced pieces only was wrong and discarded (see Formula section).
