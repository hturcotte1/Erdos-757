# Referee scratch folders

Scratch code and logs of the independent referee subagents. The reviews themselves (the part that counts) are in `results/reviews/` and are written only
by the referee and scout subagents; each review's first line is `VERDICT: ACCEPT | NEEDS-WORK | REJECT`. Index written 2026-10-15 from the review headers
(`head -1`) and from the scratch-folder references inside each review. NEEDS-WORK in the L-series reviews below concerned the proof text (false or
imprecise sentences, a DEPENDS ON line, scope wording, an overclaiming Statement in L001 round 1), not the numbers: the reviews report that the
computations were reproduced (see each review's Summary).
Some folders hold large raw dumps; `.gitignore` excludes a few logs (`rerun/*.log`).
