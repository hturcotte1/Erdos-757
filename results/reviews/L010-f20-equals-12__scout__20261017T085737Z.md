## Verdict
1. f(20) = 12 (and f(18) = 11): no source states an exact value of f(n) for any n. The only f-value in the literature is the upper bound f(14) <= 8 (A_base, Ma-Tang). Nothing mentions n = 18 or n = 20.
2. 11 tau <= 3n + 2m on the class C (linear, F7-free, e(S) <= |S|-2 hereditarily): not found in any source. The nearest published inequalities are weaker or on different parameters (quotes below).
3. Nothing citing Ma-Tang 2026, Gyarfas-Lehel 1995 or Henning-Yeo 2021 with exact small values or a 11/3/2 transversal inequality was found.

## Quoted prior work (all weaker or different)
- Ma-Tang (arXiv:2602.23282v2): lower bound h(A) >= (9/17) n from Henning-Yeo 17 tau <= 5n+3m and m <= n-2. At n = 20 (m <= 18) this gives tau <= floor(154/17) = 9, i.e. h >= 11. L010 improves this to h >= 12 (tau <= 8). Upper bound only f(14) <= 8.
- Henning-Yeo (Graphs Combin. 37 (2021) 867-890): "if H does not contain a subhypergraph isomorphic to AG(2,3) with two vertices deleted, then 17 tau(H) <= 5 n_H + 3 m_H".
- Omega issue #9804: unproved "7 tau(K) <= 3|R| + 2e2 + 4e1" (coarser, different family; not equivalent to 11 tau <= 3n + 2m).
- erdosproblems.com/757: "Ma and Tang have improved these bounds to 9/17 <= c <= 4/7"; no small-n exact values.
