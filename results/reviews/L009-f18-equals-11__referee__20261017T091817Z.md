### B. Audit of the prover's programs (read in full)

**`indep/enum_conn.c`: breadth-first canonical growth.** Vertex c processes all its remaining edges in three phases:
- A: both other vertices are old;
- B: one is old, one is new;
- C: both are new.

Completeness:
- An edge through c and a vertex created during c's own turn would repeat a pair at c, which linearity forbids. So A, B and C cover every remaining edge at c.
- Phases A and B are generated in lexicographic order; phase C in any order.
- The prunes are valid for every completion:
  - nv + 2r >= N, since each remaining edge contains the processed vertex;
  - tau(placed) >= T0 - r;
  - degree and linearity.
- A branch stops when c + 1 = nv. So only connected graphs with exactly N vertices are reported, all of them.

**`ext_indep2.c` and `ext_indep3.c`: the one-vertex extension.**
- The test "tau(H) <= TG iff some TG-transversal of G meets all three pairs" is correct when tau(G) = TG. That is checked: bad_tau counts inputs with a (TG-1)-transversal or with no TG-transversal.
- The buffers cannot overflow: C(17,7) = 19,448 < 32,768; C(16,6) = 8,008 < 8,192; at most C(17,2) = 136 < 256 pairs. In any case MAXT exits loudly.
- Pairs are restricted to endpoints of degree <= MAXDEG-1 and to pairs not inside an edge. Triples are unordered and pairwise disjoint.

**`filter_hits.c`.**
- F7: Lemma F of L007.
- (P3): the |U(F)| >= |F|+2 form, which is equivalent.
- tau: exact.

**Python helpers.**
- `combine.py`: Cartesian products on consecutive blocks; it asserts that every component covers 0..nv-1.
- `connected_filter.py`: union-find.
- `classes_of.py` and `iso_match.py`: descriptive only.

No defect found.
