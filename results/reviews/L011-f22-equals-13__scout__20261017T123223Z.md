## Quoted prior work (all weaker or different)
- Ma-Tang (arXiv:2602.23282v2): lower bound h(A) >= (9/17) n from Henning-Yeo 17 tau <= 5n + 3m and m <= n-2. At n = 22 (m <= 20): tau <= floor(170/17) = 10, i.e. h >= 12. L011 gives h >= 13. Upper bound only f(14) <= 8.
- Henning-Yeo (Graphs Combin. 37 (2021) 867-890), as cited in Ma-Tang Thm 5.3: "if H does not contain a subhypergraph isomorphic to AG(2,3) with two vertices deleted, then 17 tau(H) <= 5 n_H + 3 m_H". Weaker than 11 tau <= 3n + 2m in the cells at issue (n = 22, m = 20: HY gives tau <= 10, I11 gives tau <= 9).
- erdosproblems.com/757: "Ma and Tang have improved these bounds to 9/17 <= c <= 4/7"; no small-n exact values.
- Omega #9804: only bounds 9/17 <= c <= 4/7; unproved 7 tau <= 3|R| + 2e_2 + 4e_1 type and refuted 21 tau <= ... claims; not equivalent to I11.
