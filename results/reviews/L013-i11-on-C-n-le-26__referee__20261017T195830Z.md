## Summary

The certificate proves Theorem 1: every linear, $F_7$-free 3-graph with $e(S)\le|S|-2$ (class $C$) on at most 26 vertices
satisfies $11\tau\le3n+2m$. It does this by four induction steps $n=23,\dots,26$ on top of L011 ($n\le22$). In each step a
violator is connected (component lemma), has $\tau(H-v)=\tau-1$ and all degrees at most $\lfloor(s+8)/2\rfloor$ (degree lemma),
and so lies in one of 18 window cells. Six cells are empty by counting. The other twelve are shown empty by the L012
vertex-deletion engine, whose correctness lemma (Lemma E′) only needs I11 below the current $n$.

I re-derived all of the arithmetic by hand and with my own script, and checked the logic of Lemma E′ and the order of the
induction against the code (`engine.py`, byte-identical to L012's). I then checked the computation with my own tools, which do
not use the prover's programs or e757:
- unmodified nauty `genbg` with my own C filter, and VF2 isomorphism tests;
- my own decomposition generator;
- my own extension program, validated against a brute force;
- my own bottom-up cell engine, which reads none of the prover's files.

Results:
- All 2,039 decompositions of the 83 recursion branches are identical to the engine's. K8 changes none of them: K8 is implied
  by slack $\ge0$ when $m\le4n$.
- All 91 $\Delta\le2$ cells agree with the prover's lists, by direct enumeration. These include four top-level cells, which are
  therefore empty without any induction. 30 $\Delta\le3$ cells also agree.
- My extension program reproduces every top-level branch exactly (input counts, extensions with the required $\tau$,
