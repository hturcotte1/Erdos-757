## Verdict
1. No source states or proves 11 tau <= 3n + 2m (for linear F7-free 3-graphs, for hypergraphs with e(S) <= |S|-2, or for AP hypergraphs of (4,5)-sets), for any n. The only published inequality of this type for the class is Henning-Yeo 2021, 17 tau <= 5n + 3m, as used by Ma-Tang Thm 5.3. For comparison, at m = n-2 the two give 17 tau <= 8n-6 versus 11 tau <= 5n-4, i.e. tau <= 0.4706n versus 0.4545n; I11 is strictly stronger (and unproved in general) -- so it is not implied by the published bound.
2. No source gives exact values f(16), f(18), f(20), f(22), or any information on f(23). Erdos Problem a Day (report/757, 12 Aug 2026, status PARTIAL) claims only f(1..15) = 1,2,2,3,4,4,5,5,6,6,7,7,8,8,9 and f(17)=10, f(24)=14, f(26)=15, f(28)=16, and says it "does not require knowing f(16)"; it names n = 16 as the first case that could improve the upper bound and leaves it as a target. It lists no value at n = 16, 18, 19, 20, 21, 22, 23, 25, 27 and no inequality of the I11 form. These agree with what START_HERE section 5 already records, so L013 contradicts nothing there.
3. No source states a structural fact about the cells (23,21,10) / (25,23,11), the n = 27 cells, or the "window-cell induction". Nothing published or posted treats computer-assisted induction on the abstract class C.
4. No 2026 preprint on (4,5)-sets, Sidon subsets of weak Sidon sets, or AP-hypergraph transversals besides Ma-Tang 2602.23282 was found. No paper citing Ma-Tang, Gyarfas-Lehel 1995 or Henning-Yeo 2021 with small-n values was found (Semantic Scholar rate-limited, see Caveats).
5. Relation to the literature: L013 is a computer-assisted extension of L007-L012; its Remark 3 shows Theorem 1 gives exactly the Henning-Yeo lower bound for h at n = 23..26 (so it decides no new f value), and Remark 5 correctly records that the engine cannot go to n = 27 until Q14 (cell (23,21,10) with Delta <= 3) is solved. Nothing in the literature bears on either remark.

## Quoted prior work closest to the claim
- Ma-Tang Thm 5.3 (from Henning-Yeo 2021): "17 tau(H) <= 5 n_H + 3 m_H" for 3-uniform linear F7-free H; with Lemma 2.4 "m_H <= n_H - 2" this yields "17 tau(H) <= 8 n_H - 6". This is the strongest published bound on tau for the class; I11 (11 tau <= 3n + 2m) is stronger for every saturated m = n-2 hypergraph and is not stated in any source found.
- Erdos Problem a Day #757 (12 Aug 2026): exact values only for n <= 15 and n in {17, 24, 26, 28}; f(16) explicitly left as the first case that could improve the bound.
