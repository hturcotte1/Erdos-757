**A9. Lemma B (Step 0.7) and the code of `ext_d_fast.c`.** I read the full source.
- **Scope of the diff:** it only adds `bcov`, `cmpu32` and the `if (TG >= 2)` block. The Gosper loops are kept for $TG\le1$. `bcov` reads only `E[0..m-1]` (here `ne = m`) and writes only `covers`, `K` and `bovf`. The rest of `main` uses only `small`, `K` and `covers`.
- **Proof check (mode 1, assuming no cover of size $\le TG-1$).** Every $TG$-cover $C$ is reached by following, at each node, the first vertex of the first unmet edge that lies in $C$. The earlier siblings, which become forbidden, are not in $C$. The leaf reached is contained in $C$ and is a cover, so it equals $C$. It is reached only once: at the first node where two paths diverge, the vertex taken by one path is forbidden in the other's subtree.
- **Mode 0** returns 1 iff some cover has at most $TG-1$ vertices. That is Gosper's `small` when $TG-1\le NG$ (pad to exactly $TG-1$ vertices).
- **Order:** `qsort` makes `covers[]` ascending, which is Gosper's numeric order. So `c0`, the kill order, `nodes` and the HIT order are all identical.
- **MAXC:** exit code 3 happens iff there are more than 262,144 covers, in both versions.
- **Exit code 5** is unreachable.
- **Edge cases:** I checked $m=0$ (both versions give `bad_tau`) and $TG-1>NG$ (both give `bad_tau`). Neither occurs here ($NG\ge22$, $TG\ge8$).
