## Quoted prior work (all weaker or different)
- Ma-Tang (arXiv:2602.23282v2): lower bound h(A) >= (9/17) n from Henning-Yeo 17 tau <= 5n + 3m and m <= n-2. At n = 18 (m <= 16) this gives tau <= floor(138/17) = 8, i.e. h >= 10; the claim L009 improves to h >= 11. Upper bound only f(14) <= 8.
- Henning-Yeo (Graphs Combin. 37 (2021)): "if H does not contain a subhypergraph isomorphic to the affine plane AG(2,3) of order 3 with two vertices deleted, then 17 tau(H) <= 5 n_H + 3 m_H".
- Omega issue #9804: unproved "7 tau(K) <= 3|R| + 2e2 + 4e1" and "7 tau(H(A)) <= 3|A|" (a different, coarser inequality family, stated as unproved; not equivalent to 11 tau <= 3n + 2m).
- erdosproblems.com/757: "Ma and Tang have improved these bounds to 9/17 <= c <= 4/7"; no small-n exact values.
