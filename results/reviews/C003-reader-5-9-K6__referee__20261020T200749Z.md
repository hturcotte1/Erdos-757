## Summary

I re-verified the construction from scratch and found no problem with it.
- **The set.** 65 distinct integers, all stored as JSON ints (no floats, no strings).
- **(4,5)-property.** All 677,040 four-point subsets have at least 5 distinct distances. I checked this two ways, both literal: by counting distinct absolute differences, and by testing |B-B| >= 11.
- **Relation census.** I listed every relation a+b = c+d between distinct 2-multisets directly from the Sidon definition: once by grouping sums, and once, independently, by grouping differences. There are exactly 63 such relations. All are 3-APs, and they form a linear hypergraph with m = 63 = n-2 distinct midpoints.
- **Witness.** The 37-point witness is Sidon (checked both by sums and by differences). It is also maximal: none of the other 28 points can be added to it.
- **Upper bound h <= 37**, four independent routes:
  - (i) My own generic exact frontier dynamic program, run on the definition-level constraint hypergraph with two vertex orders. I validated it against brute force on 468 instances with n <= 22: 400 random hypergraphs, 66 induced subsets of this set, and the 11- and 20-point members of the family.
  - (ii) Two MIP solvers, HiGHS and SCIP. Both find optimum 37 and report "size >= 38" infeasible.
  - (iii) An exact, human-checkable structural proof (section 2.4). The set is exactly 269^6 * (O u phi(O) u ... u phi^6(O)). A telescoping bound over the seven affine copies of O then gives h <= 37. The per-copy inequality behind it was checked on all 2^11 subsets of O by two separate implementations.
  - (iv) A counting DP. Its full size distribution of Sidon subsets matches the structural chain count exactly: 1,281,350,529 maximum Sidon subsets, all of size 37.
- **Ratio.** With exact Fractions, 4/7 - 37/65 = 1/455 > 0 (7·37 = 259 < 260 = 4·65).
- **Frozen judge.** Re-run here, it prints `JUDGE: PASS NEW-RECORD ... n=65 h=37 ratio=37/65` and exits 0, agreeing with my h.

So f(65) <= 37, and by [published] K1 (c* = inf f(n)/n, Ma–Tang Thm 1.5) **c* <= 37/65 < 4/7**.

My only remarks concern attribution and scope, not validity. This is a third-party [community] construction (erdosproblemaday.com, reader submission 7bkzb8); the claim notes say so correctly. This review covers only the 65-point set. It does not cover the every-depth statement c* <= 5/9.

### 4. Exact structural proof of h <= 37 (human-checkable)

Command: `python3 -I experiments/referee/C003-round1/structure_proof.py <claim>`. Log: `structure_proof.log`. A second implementation of the finite facts on O is in `F1F2_second_impl.log`.

Setup: O = {0,49,75,83,98,101,117,119,121,159,269}, phi(x) = 101 + 18x/269, and C_j = phi^j(O) for j = 0..6. The following was verified exactly:
- **(a) The set.** 269^6 · (C_0 u ... u C_6) equals the claim set exactly (its max is 269^7).
- **(b) Overlaps.** Each |C_j| = 11. Consecutive copies meet in C_{j-1} n C_j = a_j := phi^j{0,269}, which equals phi^{j-1}{101,119} =: b_{j-1}. Copies at distance >= 2 are disjoint. So the set is the disjoint union C_0 u (C_1 \ a_1) u ... u (C_6 \ a_6), and 65 = 11 + 6·9.
- **(c) Finite facts on O.** O has exactly 9 APs and alpha(O) = 7. For every AP-free T in O, with s = T n {0,269} and s' = T n {101,119}:
  - (F1) |T| <= 6 + [s' nonempty];
  - (F2) |T \ {0,269}| <= 5 + [s' nonempty] - [s nonempty].
  
  The full table of max |T| over (s, s') is M = [[5,6,6,6],[4,5,5,5],[4,5,5,5],[4,5,5,5]] (after subtracting |s|), with R_0 = [6,7,7,7].

Proof that h <= 37:
1. Let T be a Sidon subset. It contains no 3-AP, because a 3-AP is the sum relation x+z = y+y.
2. phi^j is an increasing affine bijection from O onto C_j, so it carries APs to APs in both directions. Hence phi^{-j}(T n C_j) is an AP-free subset of O. Its traces on {0,269} and {101,119} are the preimages of T n a_j and T n b_j.
3. Therefore
   |T| = |T n C_0| + sum_{j=1..6} |T n (C_j \ a_j)|
       <= (6 + [T n b_0 != 0]) + sum_{j=1..6} (5 + [T n b_j != 0] - [T n b_{j-1} != 0])
       = 36 + [T n b_6 != 0] <= 37.

This bound needs neither the (4,5)-property nor the absence of cross-copy relations. It uses only the affine copies of O and their overlap pattern; scaling by 269^6 preserves h.

Two further checks:
- The census of the claim set (63 relations) equals {phi^j(e) : e an AP of O, j = 0..6}: 63 = 7·9 images, each inside one copy.
- The exact max-plus chain evaluation gives 37.

The lower bound is the witness, so h = 37.
