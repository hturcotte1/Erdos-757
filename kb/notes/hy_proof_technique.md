## 2. Main result, as stated by the sources [published]

- Abstract (Springer, verbatim in kb/notes/henning_yeo_2021_affine.md): 3-uniform H with n_H vertices and m_H edges; if H has no subhypergraph isomorphic to AG(2,3) with two vertices deleted (= F_7 of 1802.01825 Fig. 2), then 17τ(H) ≤ 5n_H + 3m_H. Corollary: graphs with δ ≥ 3, no 4-cycles and no specified 12-vertex subgraph have γ_t ≤ (8/17)n.
- Ma–Tang Thm 5.3 = [HY21, Thm 7]: linear is a hypothesis in Ma–Tang's statement (the abstract omits it; the title has it).
- Chain of context [published, abstract]: 4τ ≤ n+m (Tuza 1990; Chvátal–McDiarmid 1992), 6τ ≤ 2n+m (CM), equality characterised for linear H in Henning–Yeo JGT 59 (2008) and DM 313 (2013). The 17-bound is presented as "these bounds can be improved if we impose structural properties".
- Equality cases of 4τ ≤ n+m for connected linear 3-uniform H: the single edge E_3, F_7 (τ=3), F_8 (τ=4) [1802.01825, Thm 2, p. 4; sources/henning_yeo/henning_yeo_1802.01825_sec2_motivation.txt]. Henning–Löwenstein 1401.4851 (p. 2) says the *non-linear* extremal families for k = 3 are "three infinite families plus two special hypergraphs of orders 7 and 8", so for linear H the 3 infinite families are not linear, and the order-7 and order-8 specials are F_7 and F_8. [published]
  So the 17-bound is, in spirit, 4τ ≤ n+m with the finite linear exceptions F_7 and F_8 (F_8 contains F_7) excluded and the coefficients re-optimised; F_9 = AG(2,3) has 4τ = 20 < 21 = n+m (not an equality case) but violates 17τ ≤ 5n+3m (see 3.2). [derived-here]

## 3. What the proof probably does

### 3.1 Template evidence: the same authors' accessible proofs [published]
All of these are minimal-counterexample arguments with a linear potential Φ = c_τ·τ − c_n·n − c_m·m and local reductions "delete a vertex set X (and the edges meeting it), put a subset T ⊆ X into the transversal, check that the potential change is non-positive".

1. **Thomassé–Yeo 2007, Thm 1** (4τ ≤ n+m for all 3-uniform H; HAL copy `thomasse_yeo_2007_combinatorica.txt`, pp. 2): induction on |V|. (i) a vertex of degree ≥ 3 goes into T (1 vertex = 4, costs 1 + 3 = 4); (ii) so Δ ≤ 2; edge abc with d(a)=2, d(b)=1: delete {a,b}, put a in T; (iii) edge with no degree-2 vertex: delete it; (iv) 2-regular: find a minimal cycle of edges x_1y_1x_2, …, x_ky_kx_1, delete {x_i} (and y_k if k odd), take every second x_i. Fully reproducible, 1 page.
2. **Thomassé–Yeo 2007, Thm 3** (21τ ≤ 5n + 4p + 3s/2 + d, 4-uniform): counterexample minimal w.r.t. the **lexicographically ordered degree sequence** (not just n+m); this permits *splitting a vertex* into two (Claim 2) and adding a dummy vertex ω to an edge (Claim 6) while staying "smaller". Bookkeeping written as "+x − y − z − t" (value of vertices put in T, minus removed edges, removed vertices, change of values of remaining edges). Claims 1–15+ progressively give Δ ≤ 3, no degree-2 vertex in two plain edges, no 3-/4-degenerate edge, edges meet in ≤ 2 vertices, …
3. **Henning–Yeo arXiv:1802.01825, Thm 21 (deficiency method)**, linear 4-uniform, Δ ≤ 3: 45τ ≤ 6n + 13m + def(H), where def(H) = max over families X of vertex-disjoint "special" subhypergraphs (15 hypergraphs with τ, n, m listed in Observation 1 and verified by computer) of Σ w(F) − 13|E*(X)|, E*(X) = outside edges touching X. Proof: minimal counterexample on n+m; Claim A connected; Claim B (no X-transversal of weight |T| meeting all of E*(X)); Claims D/E via Hall's theorem on the bipartite graph G_X (X versus E*(X)) giving |E*(X)| ≥ |X|+1, hence def(H)=0; Claims G–H (a potential Φ(H') < 0 for every smaller H'); long case analysis in Claims H.1–H.5 on how an added contraction edge overlaps. Excerpt: `henning_yeo_1802.01825_sec7_deficiency.txt`. The book devotes pp. 53–135 to this method.
4. **Henning–Yeo EJC 24(2) P2.50** (Δ ≤ 2, k odd): not a reduction argument. Uses the **dual graph** G_H (vertices = edges of H, edges = degree-2 vertices) and the identity α'(G_H) = |E(H)| − τ(H) (Prop. 9, p. 6 of the PDF), then a lower bound on the matching number of a connected graph of bounded degree (Theorem 3 there, from Henning–Yeo's matching paper). File: kb/literature/papers/henning_yeo_ejc_2017.pdf.
5. **Henning–Löwenstein 1401.4851**: for the equality cases of CM, an induction on n with Claims A–G (δ ≥ 1; Δ ≤ 2 or 3; …), plus **Shannon/Vizing edge-colouring** to get matchings in multigraphs (Thm 2 there: α'(G) ≥ m/⌊3d/2⌋).
6. **Henning–Yeo arXiv:1504.02650** (3-regular 4-uniform, τ ≤ 3n/8 and τ ≤ n/4 + m/6 for Δ ≤ 3): family B of "bad" hypergraphs built by operations (A)–(D), counters b_i(H) (number of disjoint bad pieces touched by exactly i other edges), minimal counterexample with Claims 1–21 (e.g. "no two 3-edges overlap in 2 vertices", "H is 3-regular"). F_7 appears there at line 1855 of the text as the component forced by equality.

### 3.2 What these suggest for 17τ ≤ 5n + 3m [heuristic, plus derived-here arithmetic]
- **Weights.** Each vertex put in T is worth 17; each deleted vertex 5; each deleted edge 3. Check on small pieces [derived-here, exact arithmetic]: single edge n=3, m=1, τ=1: 17 ≤ 18 (slack 1). F_7: n=7, m=5, τ=3: 51 > 50 (violates by 1). F_8: 68 > 64 (by 4). F_9 = AG(2,3): n=9, m=12, τ=5: 85 > 81 (by 4). (Thus F_7 is the cheapest violator, which is why it is the forbidden configuration. This matches kb/notes/henning_yeo_2021_affine.md.)
- **Degree ≥ 4 is trivially reducible** [derived-here]: deleting v with its d ≥ 4 edges removes 5 + 3d ≥ 17 of potential, and v ∈ T pays 17; deleting a subhypergraph of a linear F_7-free H keeps both hypotheses. So a minimal counterexample has Δ ≤ 3, as in Thomassé–Yeo Claim 1. A degree-3 vertex deletion removes only 5 + 9 = 14 and leaves a deficit of 3, which must be recovered from structure (e.g. neighbours of degree 1, cycles, forced-pair extensions). This is the whole content of the proof: showing that in a Δ ≤ 3 linear F_7-free minimal counterexample, a "good" cluster exists. [heuristic] The Δ ≤ 3 reduction is nearly certain to be in the paper; the rest of the architecture I cannot confirm.
- **Why linear and F_7-free matter.** Linear removes the non-linear extremal families of 4τ ≤ n+m (infinite families of 3 types, Henning–Löwenstein p. 2). F_7-free removes the one remaining finite exception (F_8 contains F_7, F_9 contains F_7). So after both hypotheses the extremal (4τ = n+m) hypergraphs of the 1802.01825 Thm 2 reduce to E_3 alone, and 17 is presumably the best constant for which the finite local analysis closes [heuristic].
- **Likely architecture** [heuristic: I think a minimal-counterexample/deficiency proof is the most likely shape, because (a) the authors' technique of 2018–2020, (b) the 24-page length with 8 figures, (c) the book's 83-page chapter on deficiency, (d) the subsequent graph corollary needs exactly "F_7-free + linear" to be hypotheses on the open-neighbourhood hypergraph]. Possible shape: define special small hypergraphs (single edge, small ≤ 3-edge pieces, F_7-neighbours) with known τ, define a deficiency def(H) for families X of them, prove 17τ ≤ 5n + 3m + def(H) by minimal counterexample, then show def = 0 under F_7-freeness via a Hall-type count. **This is a guess; I did not read it.**
- **What is NOT known to me:** whether 17τ ≤ 5n + 3m is tight (no extremal family known to me; the best hypergraph found in kb/notes/henning_yeo_2021_affine.md has slack 1, from the single edge); the list of reducible configurations; whether linearity is used beyond forbidding multi-intersections; whether "F_7-free" is tested as a subhypergraph or induced subhypergraph (Ma–Tang use subhypergraph).

## 4. What transfers to #757 and how

1. **The method is portable.** Our abstract class C (linear, F_7-free, e(S) ≤ |S| − 2 for every vertex set S) is a *smaller* class than HY's, so one may re-run the minimal-counterexample/deficiency scheme with extra reducible configurations that only exist in C (e.g. the "no medial triangle" K31, monotone midpoints K30, e(S) ≤ |S|−2 hereditary). The window-cell induction of kb/notes/i11_conjecture.md is already a computational instance of exactly this scheme (potential 11τ − 3n − 2m).
2. **Concrete adaptation recipe** (from Thomassé–Yeo and 1802.01825) [heuristic]: choose weights (a, b, c) with c·τ ≤ a·n + b·m; compute, for every small linear F_7-free "special piece" F in class C, the slack s(F) = a n_F + b m_F − c τ_F and the *minimum over partial transversals* of the potential change when F ∪ (touching edges) is deleted; a piece with negative balance becomes a "special hypergraph"; Hall's theorem on the bipartite incidence between pieces and boundary edges (Claims D, E, H of Thm 21) then gives a deficiency inequality. Our computational census (kb/notes/gl_tight_structure.md, K47) supplies the candidate pieces.
3. **Δ ≤ 3 normalisation** [derived-here]: AP-degrees ≥ 4 are always reducible for any weights with a + b·d ≥ c at d = 4; in HY's weights equality holds at d = 4 (5 + 12 = 17). For I11 (11τ ≤ 3n + 2m) a degree-d vertex costs 3 + 2d, which is ≥ 11 for d ≥ 4 as well; consistent with K44 (degree bounds in GL-tight sets) and with L012 (n = 23 record cell has all degrees ≤ 3).
4. **Dual-graph route for Δ ≤ 2** (EJC 2017, Prop. 9): for max AP-degree 2 the problem is a matching problem, h = n − m + α'(G_H); this gives (5n+3)/9 (K10) and shows sets beating 5/9 need AP-degree-3 points. [published ingredient; K10 derived-here]
5. **What does NOT transfer:** the proof of 17τ ≤ 5n + 3m, being unread, cannot be quoted for finer statements (e.g. the exact equality cases, or a version that sees m ≤ n − 2). The best published slack data we have for AP hypergraphs is computed here, not taken from HY.
